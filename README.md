# Сервер 1С:Предприятие и PostgreSQL Pro для 1С на Ubuntu

Набор скриптов для быстрого развёртывания сервера 1С на Linux (Ubuntu / Debian):

| Скрипт | Назначение |
|---|---|
| [`install_1c_server.sh`](install_1c_server.sh) | Установка и обновление сервера 1С:Предприятие **8.3** или **8.5** |
| [`install_pgpro_1c.sh`](install_pgpro_1c.sh) | Установка PostgreSQL Pro для 1С (версии 14–18) |

Типовой порядок: сначала `install_1c_server.sh`, затем `install_pgpro_1c.sh`, после чего базы создаются в консоли кластера 1С с СУБД PostgreSQL.

---

## 1. Установка сервера 1С — `install_1c_server.sh`

### Быстрый старт

```bash
wget -O install_1c.sh https://github.com/shestopalovpro/server1c_ubuntu/releases/download/publish/install_1c_server.sh
chmod +x install_1c.sh
sudo ./install_1c.sh
```

При запуске скрипт спросит, какую платформу ставить:

```
Какую платформу 1С установить?
1) 8.3 — последняя версия 8.3 с сервера (latest_83.zip)
2) 8.5 — последняя версия 8.5 с сервера (latest_85.zip)
Введите номер варианта:
```

### Откуда берётся дистрибутив

Скрипт скачивает актуальный дистрибутив выбранной ветки:

| Ветка | Архив |
|---|---|
| 8.3 | `https://f1.atoldriver.ru/1c/latest_83.zip` |
| 8.5 | `https://f1.atoldriver.ru/1c/latest_85.zip` |

В архиве лежат DEB-пакеты платформы (`common`, `server`, `ws`, `crs` и языковые `-nls`). Номер версии скрипт определяет по именам пакетов, например `1c-enterprise-8.3.27.2342-server_8.3.27-2342_amd64.deb` → `8.3.27.2342`. Если в архиве окажется версия не той ветки (например, 8.3 в `latest_85.zip`), установка будет остановлена.

### Параметры

| Параметр | Описание |
|---|---|
| `--version=8.3` / `--version=8.5` | Выбрать ветку без интерактивного вопроса (удобно для автоматизации) |
| `--timezone=<зона>` | Часовой пояс при первичной настройке, например `Asia/Irkutsk`. Без параметра — выбор из списка |
| `--keep-archive` | Не удалять скачанный zip после установки |
| `--force-setup` | Повторить первичную настройку системы, даже если 1С уже установлена |
| `-y`, `--yes` | Не спрашивать подтверждение при переходе между ветками 8.3 ↔ 8.5 |
| `-h`, `--help` | Справка |

Примеры:

```bash
sudo ./install_1c.sh --version=8.3                            # поставить/обновить 8.3
sudo ./install_1c.sh --version=8.5 --timezone=Europe/Moscow   # чистый сервер на 8.5
sudo ./install_1c.sh --version=8.3 --keep-archive             # оставить zip в /opt/1c-archives
```

Для регулярного автообновления можно добавить в cron (запуск от root):

```bash
0 3 * * 0 /root/install_1c.sh --version=8.3 >/dev/null 2>&1
```

### Что делает скрипт по шагам

1. **Выбор ветки** — 8.3 или 8.5 (вопрос или параметр `--version`).
2. **Проверка установленных версий** в `/opt/1cv8/x86_64`. Сравнение идёт только внутри выбранной ветки: установленная 8.3 не мешает поставить 8.5 и наоборот.
3. **Первичная настройка системы** — только если 1С на сервере ещё нет (или указан `--force-setup`):
   - `apt-get update` и `apt-get upgrade`;
   - локали `ru_RU.UTF-8` и `en_US.UTF-8`, системная локаль `ru_RU.UTF-8`;
   - часовой пояс;
   - зависимости платформы: шрифты Microsoft (`ttf-mscorefonts-installer`, EULA принимается автоматически), `imagemagick`, `unixodbc`, `libgsf-bin`, `t1utils`, `unzip`, `wget`.
4. **Скачивание и разбор архива**, определение версии.
5. **Сравнение версий.** Если установлена такая же или более новая версия этой ветки — скрипт сообщает об этом и завершается, ничего не меняя.
6. **Установка пакетов** через `apt-get install` в порядке `common → server → ws`, затем остальные (`crs`, `-nls`). Недостающие зависимости подтягиваются из репозиториев автоматически.
7. **Переключение службы.** Службы `srv1cv8-*` других версий (прежняя версия этой ветки или другая ветка) останавливаются и убираются из автозапуска — порты у них общие (1540, 1541, 1560–1591). Новая служба `srv1cv8-<версия>@default` регистрируется в systemd, включается в автозапуск и запускается.
8. **Уборка.** Временные файлы удаляются, DEB-пакеты сохраняются в `/opt/1c-packages/<версия>`, архив — по желанию (`--keep-archive`).

### Переход между 8.3 и 8.5

Если на сервере стоит 8.3, а выбрана 8.5 (или наоборот), скрипт предупредит и попросит подтверждение. После установки:

- старая платформа **остаётся** в `/opt/1cv8/x86_64/<версия>` — её можно вернуть, переключив службы вручную;
- служба старой версии остановлена и отключена, работает новая.

Вернуться на прежнюю версию:

```bash
systemctl disable --now srv1cv8-8.5.1.1529@default
systemctl enable --now srv1cv8-8.3.27.2342@default
```

> Перед переходом на 8.5 сделайте резервные копии баз и убедитесь, что ваши конфигурации и лицензии поддерживают эту платформу.

### Где что лежит

```
/opt/
├── 1cv8/x86_64/<версия>/      # Установленные версии платформы
├── 1c-packages/<версия>/      # DEB-пакеты каждой установленной версии (для переустановки)
├── 1c-archives/               # Скачанные zip (только с --keep-archive)
└── install-1c/                # Временная папка распаковки (очищается после установки)
/var/log/1c_install.log        # Журнал всех запусков
```

### Полезные команды после установки

```bash
systemctl status 'srv1cv8-*'                     # состояние сервера 1С
journalctl -u 'srv1cv8-*' -n 100                 # последние сообщения службы
ls /opt/1cv8/x86_64                              # установленные версии
```

### Повторная установка из сохранённых пакетов

Пакеты из `/opt/1c-packages` можно поставить без скачивания:

```bash
sudo apt-get install -y /opt/1c-packages/8.3.27.2342/*.deb
```

## 2. Установка PostgreSQL Pro для 1С — `install_pgpro_1c.sh`

Ставит сборку PostgreSQL от Postgres Professional, адаптированную для 1С, из официального репозитория `repo.postgrespro.ru`, и создаёт кластер с локалью `ru_RU.UTF-8`.

### Быстрый старт

```bash
wget -O install_pgpro_1c.sh https://github.com/shestopalovpro/server1c_ubuntu/releases/download/publish/install_pgpro_1c.sh
chmod +x install_pgpro_1c.sh
sudo ./install_pgpro_1c.sh
```

### Варианты запуска

```bash
sudo ./install_pgpro_1c.sh                             # спросит версию (14–18)
sudo ./install_pgpro_1c.sh 16                          # версия 16, данные в /data/postgres/
sudo ./install_pgpro_1c.sh 17 --data-dir /mnt/pgdata   # своя папка для данных
./install_pgpro_1c.sh --help                           # справка
```

| Параметр | Описание | По умолчанию |
|---|---|---|
| `<версия>` | Версия PostgreSQL Pro 1C: 14, 15, 16, 17 или 18 | спрашивается |
| `--data-dir <путь>` | Каталог данных кластера (указывается после версии) | `/data/postgres/` |

### Что делает скрипт

1. Подключает репозиторий `postgrespro-1c-<версия>`.
2. Устанавливает пакеты `postgrespro-1c-<версия>` и `postgrespro-1c-<версия>-dev`.
3. Настраивает локаль `ru_RU.UTF-8` (обязательна для баз 1С).
4. Останавливает службу, удаляет кластер по умолчанию и инициализирует новый в каталоге данных с локалью `ru_RU.UTF-8`.
5. Запускает PostgreSQL и включает автозапуск.

> ⚠️ Если каталог данных не пуст, скрипт спросит подтверждение и **удалит его содержимое**. Не запускайте его на сервере с рабочими базами без резервной копии.

После установки задайте пароль пользователю `postgres` — он понадобится при создании баз в 1С:

```bash
sudo -u postgres /opt/pgpro/1c-16/bin/psql -c "ALTER USER postgres PASSWORD 'ваш_пароль';"
```

## Требования

- Ubuntu 20.04+ или Debian 11+ (x86_64);
- права root (`sudo`);
- доступ в интернет (дистрибутив 1С, репозитории Ubuntu и PostgreSQL Pro);
- свободное место: ~2,5 ГБ на каждую версию платформы (архив ~0,7 ГБ + сохранённые пакеты + установленная платформа).

Перед использованием на рабочем сервере проверьте скрипты на тестовой машине.
